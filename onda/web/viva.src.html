Onda Viva

Um programa que se observa a correr, gera versões mais rápidas de si próprio, verifica cada uma contra o seu significado e só usa as que passam. O compilador está dentro do próprio programa.

Diário de decisões

    O significado é o código

    Significado em Onda · edita e o ciclo recomeça
    Testes aprendidos

      O sistema guarda cada píxel que já apanhou uma forma errada, e as formas novas são testadas primeiro nesses píxeis. Se voltares a um código anterior, o mesmo hash devolve as formas já verificadas sem compilar nada.

      O ciclo

      1. Significado. O código corre primeiro num intérprete simples e lento, que não otimiza nada. É ele que define o que é correto, e é identificado pelo hash do código.
      2. O compilador é julgado. Antes de gerar o que quer que seja, o compilador embutido compila-se a si próprio e tem de dar o SHA-256 da semente.
      3. Formas. O compilador gera versões rápidas para CPU (JavaScript) e para GPU (GLSL). Uma forma CPU tem de dar os mesmos bits que o significado. Uma forma GPU calcula com 32 bits, por isso tem de cumprir a tolerância que o próprio significado declara: no exemplo, ±8/255 por canal em 95% dos píxeis.
      4. A medição escolhe. Das formas verificadas, fica a mais rápida neste aparelho. Sem GPU, fica a CPU.
      5. Vigilância. Enquanto corre, 32 píxeis ao acaso são comparados com o significado a cada 1,5 s. Uma forma CPU que falhe num só píxel é despromovida; uma forma GPU, quando sai claramente da sua tolerância. Os píxeis onde falharam passam a ser testes.
      6. O juiz é testado. Uma forma com um erro injetado de propósito tem de ser rejeitada. Se passasse, o juiz não estaria a funcionar.

      Limites

      • Mudar o comportamento do programa é mudar o significado, e isso não é automático: decides tu, ou uma especificação. O sistema só melhora a velocidade, e nunca pode tornar o programa errado.
      • A verificação é por amostragem: prova a igualdade nos píxeis testados, não em todos. Um erro raro pode passar até a vigilância o apanhar.
      • O significado e as formas cobrem a parte pura da Onda, a que também corre na GPU. Memória e escrita no ecrã ficam na CPU.
