A fonte, em Onda

# campo fluido: as ondas deformam as proprias coords (warp)
: px fffffff>i x y t w h tx ty {
  = u / - x * 0.5 w h
  = v / - y * 0.5 h h
  = pu + u * 0.45 Cs + * 3.0 v * 0.6 t   # warp
  = pv + v * 0.45 Sn + * 3.0 u * 0.7 t
  = a Sn + + * 6.0 pu * 5.0 pv * 1.3 t
  = b Sn + - * 5.0 pu * 6.0 pv * 1.1 t
  = cc Sn + * 7.0 Sq + * pu pu * pv pv * -2.0 t
  = g mistura(a, b, cc, toque)
  cor rosa/ambar(g) }

A mesma Onda compila-se a si própria e corre em C, WASM, x86-64, ARM64 nativo e GPU — o juiz confirma que todas dão o mesmo resultado, ao bit. C só serve de referência; aqui não corre nenhum C.

Feito com Onda — a linguagem que se auto-compila, do silício à GPU. Sem C no caminho.
