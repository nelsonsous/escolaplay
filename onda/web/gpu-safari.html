Onda na GPU — o paradigma de campo, no teu Safari

Cada pixel é uma avaliação do campo px da Onda. Na GPU corre o GLSL que o ondac -g gera (milhares de ALUs em paralelo); ao lado, o mesmo cálculo portado para JS corre na CPU. Compara tu os dois — é o "melhor que o WASM" para trabalho data-parallel (o que uma linguagem de IA faz).

GPU vs CPU
carrega em “Comparar”
GPU: GLSL gerado pela Onda, WebGL2 CPU: porte JS da mesma função px

A mesma função de campo da Onda corre nas duas formas — na GPU é o ondac -g px, na CPU é a mesma iteração de Julia em JavaScript. WebGL2 corre no Safari 15+ (Mac e iPhone). O débito da GPU mede-se sobre a animação (render + sincronização); o da CPU sobre uma amostra de 640².
